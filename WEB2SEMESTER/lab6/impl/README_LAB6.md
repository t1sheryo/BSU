# Лабораторная работа №6
## Проектирование Web-приложения: авторизация, аутентификация пользователя, фильтры

### Выполненные задачи

#### Часть 1
✅ **Удален класс сервлет `DispatcherServlet`** и заменен на `AppDispatcherServlet`  
✅ **Удалена страница `index.html`** и заменена на `home.html` с соответствующим меню  
✅ **Добавлена команда регистрации нового пользователя** (`/register`)

#### Часть 2
✅ **Реализована авторизация пользователя** с тремя уровнями доступа:
- **Гость (GUEST)** - просмотр доступных сервисов
- **Пользователь (USER)** - просмотр всех сервисов, детальная информация
- **Администратор (ADMIN)** - полное управление сервисами (добавление, редактирование, удаление)

✅ **Команды разделены по доступности** в зависимости от уровня доступа  
✅ **Создан фильтр `AuthFilter`**, который проверяет наличие пользователя и его роль в сессии и при отсутствии перенаправляет на страницу с общей информацией о системе

### Структура проекта

#### Новые компоненты

1. **Модель `User`** (`com.app.model.User`)
   - Поля: id, username, password, email, role
   - Роли: GUEST, USER, ADMIN

2. **DAO `UserDao`** (`com.app.dao.UserDao`)
   - Работа с базой данных пользователей
   - Создание администратора по умолчанию (admin/admin123)

3. **Фильтр `AuthFilter`** (`com.app.filter.AuthFilter`)
   - Проверка авторизации для всех запросов
   - Разделение путей по уровням доступа
   - Перенаправление неавторизованных пользователей

4. **Контроллеры:**
   - `HomeController` - главная страница
   - `AuthController` - авторизация и регистрация

5. **Шаблоны:**
   - `home.html` - главная страница с меню
   - `auth/login.html` - страница входа
   - `auth/register.html` - страница регистрации

### Уровни доступа и доступные пути

#### Публичные пути (доступны всем):
- `/home` - главная страница
- `/login` - страница входа
- `/register` - страница регистрации
- `/services/available` - доступные сервисы
- `/css/*` - статические ресурсы

#### Пути для пользователей (USER и ADMIN):
- `/services` - все сервисы
- `/services/{id}` - детальная информация о сервисе

#### Пути только для администраторов (ADMIN):
- `/services/create` - добавление нового сервиса

### Учетные данные по умолчанию

**Администратор:**
- Имя пользователя: `admin`
- Пароль: `admin123`

### Запуск приложения

1. Соберите проект:
```bash
cd impl
mvn clean package
```

2. Запустите на Jetty:
```bash
mvn jetty:run
```

3. Откройте в браузере:
```
http://localhost:8080/home
```

### Изменения в web.xml

- Добавлен фильтр `AuthFilter` для всех запросов (`/*`)
- Заменен `DispatcherServlet` на `AppDispatcherServlet`

### Особенности реализации

1. **Фильтр авторизации** проверяет каждый запрос и определяет уровень доступа
2. **Роли пользователей** хранятся в базе данных и в сессии
3. **Меню навигации** динамически изменяется в зависимости от роли пользователя
4. **Сообщения об ошибках и успехе** отображаются на страницах
