# Телефонная станция - Список доступных сервисов

Web-приложение для управления списком доступных сервисов телефонной станции.

## Технологии

- **Java 17**
- **Maven** - управление зависимостями
- **Thymeleaf** - шаблонизатор для динамических HTML страниц
- **Jakarta Servlet API** - сервлеты для обработки HTTP запросов
- **H2 Database** - встроенная база данных
- **Logback** - логирование
- **Jetty** - контейнер сервлетов для запуска

## Структура проекта

```
src/
├── main/
│   ├── java/com/app/
│   │   ├── controller/     # Контроллеры для обработки запросов
│   │   ├── dao/            # DAO классы для работы с БД
│   │   ├── model/          # Модели данных
│   │   └── servlet/        # Сервлет-диспетчер
│   ├── resources/
│   │   └── logback.xml     # Конфигурация логгера
│   └── webapp/
│       ├── WEB-INF/
│       │   ├── templates/  # Thymeleaf шаблоны
│       │   └── web.xml     # Конфигурация web-приложения
│       └── css/
│           └── style.css   # Стили CSS
└── test/
    └── java/               # Тесты
```

### Часть 1
- ✅ Сервлет-диспетчер передает управление контроллерам

- ✅ Результаты отображаются на динамических HTML страницах Thymeleaf
- ✅ Каждому пользователю соответствует объект сессии
- ✅ В cookies сохраняется информация о времени последнего визита и количестве посещений

### Часть 2
- ✅ Создана главная страница index.html с информацией о системе и меню
- ✅ Проработана обработка исключений
- ✅ Подключен логгер (Logback)
- ✅ Создана страница error.html для отображения ошибок
- ✅ Использованы CSS стили для оформления

## Запуск проекта

### Требования
- Java 17 или выше
- Maven 3.6+

### Команды

1. **Сборка проекта:**
```bash
mvn clean package
```

2. **Запуск на Jetty:**
```bash
mvn jetty:run
```

3. **Доступ к приложению:**
После запуска приложение будет доступно по адресу:
```
http://localhost:8080
```

## Страницы приложения

- `/` или `/index` - Главная страница с информацией о системе
- `/services` - Список всех сервисов
- `/services/available` - Список только доступных сервисов
- `/services/create` - Форма добавления нового сервиса
- `/services/{id}` - Детальная информация о сервисе
- `/error` - Страница ошибки

## База данных

Используется встроенная H2 база данных в памяти. При первом запуске автоматически создается таблица `services` и заполняется тестовыми данными.

### Тестовые данные
- Исходящие звонки (10.50 руб.)
- Входящие звонки (5.00 руб.)
- SMS (3.00 руб.)
- Интернет (15.00 руб.)
- Роуминг (25.00 руб.) - недоступен

## Сессии и Cookies

При каждом запросе:
- Обновляется счетчик посещений в сессии
- Сохраняется время последнего визита в сессии
- В cookies сохраняется:
  - `lastVisit` - дата и время последнего визита
  - `visitCount` - общее количество посещений

## Логирование

Логи сохраняются в:
- Консоль (INFO уровень и выше)
- Файл `logs/application.log` (все уровни)

## Обработка ошибок

Все исключения перехватываются и обрабатываются:
- Критические ошибки (например, проблемы с БД) перенаправляются на страницу `/error`
- Информация об ошибке логируется
- Пользователю показывается понятное сообщение об ошибке
